# ControlPad

태블릿 화면에 버튼을 직접 그려서 PC용 리듬게임 컨트롤러나 작업용 단축키 패드로 쓰는 안드로이드 앱입니다.

## 설치

`release/ControlPad.apk` 를 태블릿에 내려받아 설치합니다(안드로이드 9 이상). 처음 설치할 때
"출처를 알 수 없는 앱" 설치를 허용해야 합니다.

## 사용법

1. **레이아웃 만들기** — `＋ 새 레이아웃`에서 빈 레이아웃이나 예시(4키, 7키, 단축키)를 고릅니다.
2. **버튼 그리기** — 편집 화면의 빈 곳을 손가락으로 드래그하면 그 크기로 버튼이 생기고, 입력할 키를 고르는 창이 뜹니다.
   - 버튼을 끌면 이동, 선택한 버튼의 오른쪽 아래 흰 점을 끌면 크기 조절
   - 선택된 버튼을 한 번 더 누르거나 `속성`을 누르면 키·이름·색·모양·동작 방식 변경
   - 키를 여러 개 고르면 조합(예: `Ctrl + Shift + S`)으로 동시에 입력됩니다
3. **동작 방식**
   - *누르고 있는 동안 입력* — 리듬게임용. 손가락을 뗄 때 키도 떼집니다
   - *누를 때 한 번 입력* — 단축키용
   - *누를 때마다 켜짐/꺼짐* — Shift 고정 같은 용도
   - `슬라이드 입력`을 켜면 손가락을 떼지 않고 옆 버튼으로 미끄러져도 입력됩니다
4. **노브** — 사운드 볼텍스, K-Shoot MANIA 같은 게임용. 편집 화면의 `＋노브`로 추가하고, 손가락으로 원을 그리듯 돌립니다.
   - *마우스 X축 / Y축* — 아날로그 입력. 게임 설정에서 노브(레이저) 입력을 마우스로 바꿔야 합니다. 보통 왼쪽 노브를 X축, 오른쪽 노브를 Y축에 둡니다
   - *키보드* — 돌리는 동안 방향에 맞는 키를 누릅니다. 게임 기본 설정(Q/W, O/P) 그대로 쓸 수 있습니다
   - 감도와 회전 방향 반전은 노브 속성에서 바꿉니다
   - `사운드 볼텍스 · KSM (노브 2개)` 예시 레이아웃은 KSM 기본 키 배치(BT = S D K L, FX = C M, 노브 = Q/W, O/P)입니다
5. **트랙패드** — 편집 화면의 `＋트랙패드`로 추가합니다.
   - 한 손가락으로 움직이면 마우스 이동, 탭하면 좌클릭
   - 두 손가락으로 움직이면 스크롤, 두 손가락 탭은 우클릭
   - 드래그하려면 키 선택의 `마우스 버튼 > 좌클릭`을 넣은 버튼을 따로 그려 누른 채로 트랙패드를 움직입니다
   - 포인터 속도와 탭 클릭 여부는 트랙패드 속성에서 바꿉니다
6. **가상 마우스** — 편집 화면의 `＋마우스`로 추가하는 마우스 모양 컨트롤입니다.
   - 위쪽 왼쪽·오른쪽: 좌클릭·우클릭 (누르고 있는 동안 유지)
   - 위쪽 가운데: 휠. 위아래로 밀면 스크롤, 톡 누르면 휠클릭
   - 아래쪽 몸통: 문지르면 마우스 이동. 좌클릭을 누른 채 몸통을 움직이면 드래그
7. **퀵 리스타트** — 편집 화면의 `＋재시작`으로 게임에 맞는 재시작 버튼을 추가합니다.
   - 사운드 볼텍스: `Enter + Space + R Alt`
   - DJMAX · EZ2ON: `F5`
   - 4키·7키·사운드 볼텍스 예시 레이아웃에는 처음부터 들어 있습니다
8. **표시 버튼(그룹)** — 누르면 지정해 둔 버튼들이 나타나는 버튼입니다.
   - 편집 화면의 `＋표시 버튼`으로 추가하고, 나타나게 할 그룹(1~8)을 고릅니다
   - 나타나게 할 버튼은 각 버튼의 `속성 > 표시 조건`에서 같은 그룹으로 지정합니다. 편집 화면에서는 왼쪽 위에 `그룹 N` 표시가 붙고, 실행 화면에서는 표시 버튼을 누르기 전까지 숨겨집니다
   - 동작 방식: 누를 때마다 나타남/사라짐, 또는 누르고 있는 동안만 나타남
   - 그룹이 사라지면 그 그룹 버튼이 누르고 있던 키는 자동으로 떼집니다
9. **실행** — 목록에서 레이아웃을 누르면 전체 화면 컨트롤러가 됩니다. 뒤로 가기로 나옵니다.

## 키 표시

`연결 설정 > 기타`에서 켜고 끕니다.

- **눌리고 있는 키 표시** — 실행 화면 위쪽 가운데에 지금 입력 중인 키(예: `Ctrl + S`)를 보여 줍니다. 짧게 누른 키는 뗀 뒤에도 잠깐 남습니다
- **버튼에 키 이름 표시** — 버튼 아래쪽의 작은 키 이름

## 테마

`연결 설정 > 테마`에서 앱 전체의 색을 고릅니다. 고르면 바로 아래 미리보기에 버튼이 어떻게 보이는지 나옵니다.

- 기본 제공 14종: 다크, 블랙, 라이트, 네온, 미드나잇, 포레스트, 와인, 선셋, 오션, 그레이, 사이버펑크, 라벤더, 민트, 벚꽃
- **커스텀**: 배경색, 글자색, 버튼 색 진하기, 테두리 굵기, 글자를 버튼 색으로 표시할지를 직접 정합니다. 처음 고르면 쓰고 있던 테마에서 시작합니다
- 버튼 색도 속성 창의 `＋` 칸에서 원하는 색으로 고를 수 있습니다

## PC와 연결

`연결 설정`에서 둘 중 하나를 고릅니다.

### 블루투스 키보드 (기본)

PC에 아무것도 설치하지 않습니다. 태블릿이 블루투스 키보드로 인식됩니다.

1. 앱의 `연결 설정`에서 `PC에서 검색 허용`을 누릅니다.
2. PC의 블루투스 설정에서 장치 추가로 태블릿을 찾아 연결합니다.
3. 다음부터는 앱을 켜면 마지막 PC에 자동으로 연결됩니다.

이미 태블릿과 PC가 페어링되어 있었거나 이전 버전에서 페어링했다면(1.2에서 마우스 기능이 바뀜) 양쪽에서 페어링을 지우고, 앱의 연결 설정 화면을 켠 상태로 다시 페어링하세요.
일부 기기는 제조사가 이 기능(HID 기기 프로필)을 꺼 두어 쓸 수 없습니다. 그때는 아래 방식을 쓰세요.

### Wi-Fi / USB 테더링

지연이 가장 적습니다. PC(Windows)에 [Python](https://www.python.org/downloads/)이 있어야 합니다.

```bash
python receiver/controlpad_receiver.py
```

창에 표시되는 PC 주소를 앱의 `연결 설정`에 입력하고 `저장하고 연결 확인`을 누릅니다.
Windows 방화벽이 물으면 허용하세요. 관리자 권한으로 실행된 게임에 입력하려면 수신 프로그램도 관리자 권한으로 실행해야 합니다.

## 업데이트

앱을 켜면 새 버전을 확인하고, 있으면 묻지 않고 바로 내려받아 설치합니다(`연결 설정 > 자동 업데이트`, 기본 켜짐). 끄면 설치할지 먼저 묻습니다.
안드로이드 12 이상에서는 앱 안에서 한 번 업데이트한 뒤부터 설치 확인 창도 뜨지 않습니다. 설치가 끝나면 앱이 닫히니 다시 켜면 됩니다. `연결 설정 > 업데이트 확인`으로 직접 확인할 수도 있습니다.
처음 업데이트할 때 안드로이드가 "이 출처의 앱 설치 허용"을 한 번 묻습니다.

채널이 둘입니다.

| 채널 | 폴더 | 내용 |
|---|---|---|
| 알파 | `release/alpha/` | 가장 최신 빌드. 올리는 즉시 받습니다 |
| 정식 (기본) | `release/` | 한 번 전의 빌드. 새 빌드는 그다음 빌드가 나올 때 정식으로 넘어옵니다 |

알파를 받으려면 `연결 설정 > 알파 빌드 받기`를 켭니다.

새 버전을 배포하려면 `app/build.gradle.kts`의 `versionCode`/`versionName`을 올리고 아래를 실행한 뒤 커밋·푸시합니다.
지금 알파에 있던 빌드가 정식으로 내려가고, 새 빌드가 알파에 올라갑니다.

```bash
scripts/publish.sh "이번 버전에서 바뀐 점"
```

버그 수정은 기다리지 않고 두 채널에 같이 올립니다.

```bash
scripts/publish.sh --fix "고친 점"
```

앱은 `Updater.kt`의 `BASE` 주소(현재 `claude/vibrant-ramanujan-pdzsly` 브랜치)에서 받아 옵니다.

## 빌드

```bash
./gradlew assembleRelease
```

결과물은 `app/build/outputs/apk/release/app-release.apk` 입니다. GitHub에 푸시하면 Actions가 같은 APK를 빌드해 artifact로 올립니다.
서명 키(`app/controlpad.keystore`)는 어디서 빌드해도 업데이트 설치가 되도록 저장소에 넣어 둔 공개 키입니다.
