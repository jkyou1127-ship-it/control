# Control Pad

태블릿 화면에 버튼을 직접 그려서 PC용 리듬게임 컨트롤러나 작업용 단축키 패드로 쓰는 안드로이드 앱입니다.

## 설치

`release/ControlPad.apk` 를 태블릿에 내려받아 설치합니다(안드로이드 9 이상). 처음 설치할 때
"출처를 알 수 없는 앱" 설치를 허용해야 합니다.

## 사용법

1. **레이아웃 만들기** — `＋ 새 레이아웃`에서 빈 레이아웃이나 예시(4키, 7키, 단축키, 사운드 볼텍스, 트랙패드, 숫자 키패드, 영문 키보드, 한글 키보드)를 고릅니다.
2. **버튼 그리기** — 편집 화면의 빈 곳을 손가락으로 드래그하면 그 크기로 버튼이 생기고, 입력할 키를 고르는 창이 뜹니다.
   - 버튼을 끌면 이동, 선택한 버튼의 오른쪽 아래 흰 점을 끌면 크기 조절
   - 선택된 버튼을 한 번 더 누르거나 `속성`을 누르면 키·이름·색·모양·동작 방식 변경
   - 키를 여러 개 고르면 조합(예: `Ctrl + Shift + S`)으로 동시에 입력됩니다
3. **동작 방식**
   - *누르고 있는 동안 입력* — 리듬게임용. 손가락을 뗄 때 키도 떼집니다
   - *누를 때 한 번 입력* — 단축키용
   - *누를 때마다 켜짐/꺼짐* — Shift 고정 같은 용도
   - *누르면 일정 시간 동안 입력* — 한 번 누르면 정해 둔 시간(0.05~60초) 동안 키를 누르고 있다가 스스로 뗍니다. 입력 중에 다시 누르면 시간을 처음부터 다시 셉니다
   - *매크로* — 한 번 누르면 정해 둔 키 조합들을 차례로 입력합니다(예: `Ctrl + C` → `Alt + Tab` → `Ctrl + V`). 속성에서 `단계 추가`로 순서를 만듭니다
   - *연타* — 누르고 있는 동안 1초에 1~30번 반복해서 눌렀다 뗍니다
   - **레이아웃 전환 버튼** — `＋추가 > 레이아웃 전환 버튼`. 실행 화면에서 누르면 다른 레이아웃으로 바로 넘어갑니다. 여러 레이아웃을 페이지처럼 오갈 때 씁니다
   - `슬라이드 입력`을 켜면 손가락을 떼지 않고 옆 버튼으로 미끄러져도 입력됩니다
4. **노브** — 사운드 볼텍스, K-Shoot MANIA 같은 게임용. 편집 화면의 `＋추가 > 노브`로 추가하고, 손가락으로 원을 그리듯 돌립니다.
   - *마우스 X축 / Y축* — 아날로그 입력. 게임 설정에서 노브(레이저) 입력을 마우스로 바꿔야 합니다. 보통 왼쪽 노브를 X축, 오른쪽 노브를 Y축에 둡니다
   - *키보드* — 돌리는 동안 방향에 맞는 키를 누릅니다. 게임 기본 설정(Q/W, O/P) 그대로 쓸 수 있습니다
   - 키보드 방식에서 `계속 누름`을 켜면, 돌리다 멈춰도 손을 뗄 때까지 키를 누르고 있습니다. 반대로 돌리면 반대쪽 키로 바뀝니다
   - 감도와 회전 방향 반전은 노브 속성에서 바꿉니다
   - `사운드 볼텍스 · KSM (노브 2개)` 예시 레이아웃은 KSM 기본 키 배치(BT = S D K L, FX = C M, 노브 = Q/W, O/P)입니다
   **조이스틱** — `＋추가 > 조이스틱 (4방향 키)`. 손잡이를 기울인 방향의 키를 누르고 있습니다.
   - 기본은 방향키이고, 속성에서 `W A S D`나 방향마다 원하는 키로 바꿉니다
   - `대각선 입력`을 켜면 비스듬히 기울일 때 두 방향 키를 함께 누르고, 끄면 항상 한 방향만 누릅니다
5. **트랙패드** — 편집 화면의 `＋추가 > 트랙패드`로 추가합니다.
   - 한 손가락으로 움직이면 마우스 이동, 탭하면 좌클릭
   - 두 손가락으로 움직이면 스크롤, 두 손가락 탭은 우클릭
   - 드래그하려면 키 선택의 `마우스 버튼 > 좌클릭`을 넣은 버튼을 따로 그려 누른 채로 트랙패드를 움직입니다
   - 포인터 속도와 탭 클릭 여부는 트랙패드 속성에서 바꿉니다
6. **가상 마우스** — 편집 화면의 `＋추가 > 가상 마우스`로 추가하는 마우스 모양 컨트롤입니다.
   - 위쪽 왼쪽·오른쪽: 좌클릭·우클릭 (누르고 있는 동안 유지)
   - 위쪽 가운데: 휠. 위아래로 밀면 스크롤, 톡 누르면 휠클릭
   - 아래쪽 몸통: 문지르면 마우스 이동. 좌클릭을 누른 채 몸통을 움직이면 드래그
7. **퀵 리스타트** — 편집 화면의 `＋추가 > 퀵 리스타트 버튼`으로 게임에 맞는 재시작 버튼을 추가합니다.
   - 사운드 볼텍스: `Enter + Space + R Alt`
   - DJMAX · EZ2ON: `F5`
   - 4키·7키·사운드 볼텍스 예시 레이아웃에는 처음부터 들어 있습니다
8. **표시 버튼(그룹)** — 누르면 지정해 둔 버튼들이 나타나는 버튼입니다.
   - 편집 화면의 `＋추가 > 표시 버튼`으로 추가하고, 나타나게 할 그룹(1~8)을 고릅니다
   - 나타나게 할 버튼은 각 버튼의 `속성 > 표시 조건`에서 같은 그룹으로 지정합니다. 편집 화면에서는 왼쪽 위에 `그룹 N` 표시가 붙고, 실행 화면에서는 표시 버튼을 누르기 전까지 숨겨집니다
   - 동작 방식: 누를 때마다 나타남/사라짐, 또는 누르고 있는 동안만 나타남
   - 그룹이 사라지면 그 그룹 버튼이 누르고 있던 키는 자동으로 떼집니다
   - 편집 화면의 `↶ 취소`로 방금 한 변경(이동, 크기, 추가, 삭제, 속성)을 최대 50번까지 되돌리고, `↷ 다시`로 되살립니다. 편집 화면을 나가면 기록은 지워집니다
   - `숨김`은 선택한 버튼을 편집 화면에서만 잠깐 안 보이게 합니다(겹친 버튼 밑의 것을 고칠 때). 아무것도 선택하지 않고 다시 누르면 모두 나타나고, 실행 화면에는 영향이 없습니다
   - **형변환** — 편집 화면 왼쪽 `형변환`으로 선택한 것을 일반 버튼, 노브, 조이스틱, 트랙패드, 가상 마우스, 표시 버튼, 레이아웃 전환 버튼, 표시 패널, 옵션 버튼 중 다른 종류로 바꿉니다. 위치·크기·색·이름은 그대로이고, 하나만 바꾸면 새 종류의 속성 창이 바로 뜹니다
   - **모양** — `모양` 도구나 버튼 속성에서 둥근 사각형, 원형, 다이아몬드, 육각형, 각진 사각형 중에 고릅니다. 누르는 범위도 그 모양을 따릅니다
9. **다중 선택** — 편집 화면의 `다중 선택`을 켜면 여러 버튼을 한꺼번에 다룹니다.
   - 버튼을 누르면 선택에 추가, 다시 누르면 해제. 손가락을 떼지 않고 훑으면 지나간 버튼이 차례로 선택됩니다(빈 곳에서 시작해도 됨)
   - 빈 곳을 톡 누르면 선택이 모두 풀립니다
   - 선택 전체를 감싸는 영역의 오른쪽 아래 흰 점을 끌면 전부 같은 비율로 커지거나 작아집니다
   - 이미 선택된 버튼을 잡고 끌면 전부 함께 이동하고, `복제`·`삭제`도 전부에 적용됩니다
   - `속성`을 누르면 표시 조건(그룹)과 색을 한꺼번에 바꿉니다
10. **버튼 색** — 속성 창에서 버튼 색(`＋` 칸으로 원하는 색), 글자색, 눌렸을 때 색을 버튼마다 따로 정합니다.
11. **키패드** — 편집 화면의 `＋추가 > 숫자 키패드`로 숫자 키패드 한 벌(0~9, `.`, `+ - * /`, Enter, 지우기)을 한 번에 넣습니다.
    - 숫자패드 키(Num 0~9) 또는 키보드 윗줄의 일반 숫자 키 중에 고릅니다
    - 넣은 직후 전부 선택되어 있어 한 덩어리로 옮길 수 있고, 그 뒤에는 보통 버튼처럼 하나씩 고칠 수 있습니다
12. **키보드** — `＋추가 > 영문 키보드` 또는 `한글 키보드`로 PC 키보드 전체를 넣습니다.
    - 한글 키보드에는 `한/영`, `한자` 키가 있고, 실행 화면에서 `한/영`을 누를 때마다 글자 키의 표시가 영문(Q W E …) ↔ 자모(ㅂ ㅈ ㄷ …)로 바뀝니다. 입력되는 키 자체는 영문 키보드와 같습니다
    - 화면을 열 때는 영문으로 시작합니다. PC의 실제 입력 상태와 어긋나면 PC 키보드로 한/영을 한 번 눌러 맞추세요
    - 다른 버튼도 `속성 > 한글 상태일 때 표시할 이름`을 적으면 같은 방식으로 바뀝니다
    - `한/영`이 PC에서 먹지 않으면 그 버튼의 키를 `R Alt`로 바꿔 보세요(PC의 한글 키보드 종류 설정에 따라 다릅니다)
13. **실행** — 목록에서 레이아웃을 누르면 전체 화면 컨트롤러가 됩니다. 뒤로 가기로 나옵니다.

## 사진과 세밀 조정

- **사진 넣기** — 편집 화면의 `＋추가 > 사진`으로 꾸미기용 사진을 넣습니다. 누를 수 없고, 버튼과 겹치면 밑의 버튼이 눌립니다. 화면 전체로 늘리고 `순서 > 맨 뒤로`를 누르면 배경이 됩니다
- **버튼 사진** — 버튼 `속성 > 사진 고르기`로 버튼 면에 사진을 넣습니다. 버튼 모양대로 잘려 들어가고, 누르면 눌림 색이 반투명하게 덮입니다. 이름을 적어 두면 사진 위에 글자가 올라갑니다
- **크기·위치 세밀 조정** — 버튼을 선택하고 `크기·위치`를 누르면 가로·세로 위치와 너비·높이를 화면 대비 %로 직접 적거나 0.1% / 1% 단위로 바꿉니다. 여러 개를 선택하면 전체를 감싸는 영역 기준으로 함께 바뀝니다
- **순서** — 겹친 것들의 위아래 순서를 `맨 앞으로` / `맨 뒤로`로 바꿉니다
- 사진은 `파일로 저장`할 때 레이아웃 파일 안에 함께 들어갑니다

## 실험실에서 켜는 편의 기능

아래 기능은 `설정 > 실험실 · 평가단`에서 하나씩 켜야 나옵니다(알파). 평가단이 정식 추가를 요청하면 정식 기능이 됩니다.

- **레이아웃 검색 · 맨 위에 고정 · 홈 화면 바로가기** — 목록 화면의 검색창과 `⋮` 메뉴
- **전체 선택 · 맞춤 · 균등 배치·같은 크기 · 버튼 잠금** — 편집 화면 왼쪽 도구 모음
- **버튼 불투명도 · 글자 크기** — 버튼 속성의 조절 막대
- **실수로 나가기 방지** — 실행 화면에서 뒤로 가기를 두 번 눌러야 나감
- **실행 화면 표시** — 초당 입력 수, 배터리·시각
- **실행 화면 설정** — 연결 상태 숨기기, 누를 때 소리, 최근 입력 기록
- **위치 · 크기 표시** — 편집 화면 아래쪽에 선택한 것의 위치와 크기(%)
- **편집 보조** — 가운데 안내선, 길게 눌러 속성 열기
- **실행 화면 보조** — 터치 위치 표시, 누른 시간 표시, 쉬는 동안(30초) 어둡게
- **편집 편의** — 큰 크기 조절 손잡이, 삭제 전에 확인, 제자리 복제
- **입력 확인** — 누를 때 화면 테두리 번쩍, 상태 표시를 아래로
- **옵션 버튼** — `＋추가 > 옵션 버튼`으로 넣고 켜고 끌 설정을 고릅니다. 실행 중에 누를 때마다 진동, 눌리고 있는 키 표시, 버튼 키 이름 표시, 실행 관련 실험실 기능이 켜지고 꺼집니다(켜져 있으면 버튼이 눌린 색)

## 오프셋

`설정 > 오프셋`에서 맞춥니다.

- **터치 위치 보정(가로·세로)** — 손가락이 닿는 자리와 버튼이 눌리는 자리가 어긋날 때, 판정 위치를 최대 40dp까지 옮깁니다(예: 늘 버튼보다 조금 아래를 누른다면 세로를 '위'로)
- **입력 지연** — PC로 보내는 입력을 0~200ms 늦춥니다. 다른 기기나 소리와 박자를 맞출 때 씁니다. 앞당기는 것은 할 수 없습니다

## 화면 · 목록 설정

- **레이아웃 미리보기** — 목록의 각 레이아웃 왼쪽에 버튼 배치가 작게 보입니다(`설정 > 화면`에서 끌 수 있음)
- **정렬** — 목록 위쪽 `정렬` 버튼을 누를 때마다 저장 순 → 이름순 → 최근 수정순으로 바뀝니다
- **화면 방향** — `설정 > 화면`에서 편집·실행 화면을 가로, 세로, 자동 회전 중에 고릅니다
- **격자 크기** — `설정 > 화면`에서 편집 화면 격자를 넓게, 보통, 촘촘 중에 고릅니다
- **모든 키 떼기 버튼** — `＋추가 > 모든 키 떼기 버튼`. 실행 중에 누르면 눌린 채로 남은 키와 켜 둔 버튼을 한 번에 풉니다

## 레이아웃 저장과 불러오기

- 편집 화면에서 바꾼 내용은 화면을 나갈 때 자동으로 저장됩니다. 도구 줄의 `저장`으로 바로 저장할 수도 있습니다
- 목록에서 레이아웃 오른쪽 `⋮ > 파일로 저장`을 누르면 `이름.controlpad.json` 파일로 내보냅니다(백업, 다른 기기로 옮기기, 공유)
- 목록 위쪽 `불러오기`로 그 파일을 고르면 새 레이아웃으로 추가됩니다. 이미 있는 레이아웃을 덮어쓰지 않습니다

## 키 표시

`설정 > 기타`에서 켜고 끕니다.

- **눌리고 있는 키 표시** — 실행 화면 위쪽 가운데에 지금 입력 중인 키(예: `Ctrl + S`)를 보여 줍니다. 짧게 누른 키는 뗀 뒤에도 잠깐 남습니다
- **표시 패널** — `＋추가 > 키 입력 표시 패널`(또는 `초당 입력 수 패널`)로 레이아웃 안에 넣습니다. 속성의 `표시할 내용`에서 눌리고 있는 키, 초당 입력 수, 콤보, 총 입력 수, 실행 시간, 배터리·시각, 최근 입력 기록, 연결 상태 중 하나를 고릅니다. `＋추가`에 종류별 패널(`콤보 패널` 등)도 따로 있습니다. 실험실 기능을 켜지 않아도 됩니다. 버튼처럼 위치·크기·색·글자색을 정할 수 있고, 패널이 있는 레이아웃에서는 위쪽의 기본 표시 대신 패널에 나옵니다
- **버튼에 키 이름 표시** — 버튼 아래쪽의 작은 키 이름

## 반응 속도

앱은 정해진 주기로 입력을 읽어 보내는 방식이 아니라, 터치가 들어오는 즉시 한 번씩 보냅니다. 그래서 반응 속도는 아래 두 가지가 정합니다.

- **터치 패널이 손가락을 읽는 횟수** — 기기에 따라 초당 60~240번. 앱에서 바꿀 수 없어 8000Hz 같은 값은 낼 수 없습니다. 실행 화면은 기기가 지원하는 가장 높은 주사율을 쓰고, 터치를 화면 갱신 주기에 묶지 않고 바로 처리합니다
- **전송 방식** — 블루투스는 규격상 약 11ms(초당 90번 정도) 간격이 한계입니다. 지연에 민감한 리듬게임은 Wi-Fi / USB 테더링 방식을 쓰세요. 실행 화면이 떠 있는 동안 Wi-Fi 절전을 꺼서 지연을 줄입니다

Wi-Fi 방식에서는 실행 화면 왼쪽 위와 설정에 `왕복 Nms`가 표시됩니다. 태블릿에서 PC까지 갔다가 돌아오는 시간이라, 이 숫자가 크면(대략 20ms 이상) 공유기나 Wi-Fi 신호 쪽 문제입니다.

## 테마

`설정 > 테마`에서 앱 전체의 색을 고릅니다. 고르면 바로 아래 미리보기에 버튼이 어떻게 보이는지 나옵니다.

- 기본 제공 20종: 다크, 블랙, 라이트, 네온, 미드나잇, 포레스트, 와인, 선셋, 오션, 그레이, 사이버펑크, 라벤더, 민트, 벚꽃, 레트로, 오로라, 코랄, 슬레이트, 크림, 고대비
- **테마 에디터** — `설정 > 테마 에디터`에서 나만의 테마를 여러 개 만들어 이름을 붙여 둡니다. 배경색, 글자색, 목록 항목 배경색, 버튼 바탕색, 버튼 색 진하기, 테두리 굵기, 글자를 버튼 색으로 표시할지를 정하고, 바꾸는 대로 미리보기에 반영됩니다. 저장한 테마는 테마 목록 맨 아래에 나옵니다
- 버튼 색도 속성 창의 `＋` 칸에서 원하는 색으로 고를 수 있습니다

## 그리기 (그림 버튼)

편집 화면 왼쪽의 `✎ 그리기`를 켜면 손가락으로 그린 그림이 그대로 버튼이 됩니다. 목록 화면의 `✎ 그림 레이아웃`은 새 레이아웃을 만들고 그리기를 켠 채로 편집 화면을 엽니다.

1. 위쪽 펜 도구 줄에서 색과 굵기를 고르고 화면에 버튼 모양을 그립니다. `안쪽 채우기`를 켜면 닫힌 모양의 안쪽이 옅게 칠해집니다
2. `✔ 버튼으로 만들기`를 누르면 무엇으로 만들지 고릅니다: 일반 버튼, 노브, 조이스틱, 트랙패드, 가상 마우스, 표시 버튼, 레이아웃 전환 버튼, 표시 패널. 그린 그림이 그 요소의 면이 되고, 같은 종류의 다른 요소와 같은 속성 창이 뜹니다
3. `✎ 그리기`를 끄면 평소처럼 옮기고, 크기를 바꾸고, 다른 요소를 추가할 수 있습니다

그린 버튼은 누르면 그린 부분이 눌림 색으로 바뀝니다. 누를 수 있는 범위는 그림을 감싸는 사각형입니다.

## 실험실과 평가단 (알파)

`설정 > 알파 빌드 받기`를 켜면 설정에 `실험실 · 평가단`이 나타납니다.

- **실험실 사용** — 실험실 전체를 한 번에 켜고 끕니다(설정 맨 위, 실험실 화면 맨 위). 끄면 실험실에서 켜 둔 기능이 모두 꺼지고, 다시 켜면 전에 골라 둔 대로 돌아옵니다
- **올라간 기능의 자리** — 평가단 건의로 알파·정식에 올라간 기능 중 동작을 바꾸는 것(표시, 진동, 소리, 밝기 등)은 설정 화면 `기능` 칸의 켜기/끄기가 되고(처음엔 켜짐), 버튼·도구인 것(검색, 고정, 맞춤, 잠금, 옵션 버튼 등)은 그 버튼이 그냥 생깁니다
- **실험실** — 다듬는 중인 기능을 하나씩 켜 봅니다. 목록은 위의 '실험실에서 켜는 편의 기능'에 있습니다
- **평가단** — 알파 빌드나 실험실 기능을 건의합니다. 반영되기 전에 취소할 수 있습니다(이슈를 닫거나, 중계 서버를 쓰면 `Actions > Panel request`의 실행을 취소)
  - 빌드 정식 추가: 바로 요청한 그 알파 빌드가 정식 채널(`release/`)로 올라갑니다
  - 실험실 기능 정식 추가: 바로 `release/labs.json`의 `graduated`로 옮겨 모두에게 켜집니다
  - 숨김: 기다리지 않고 바로 그 기능이 `hidden`에 올라가 실험실 목록에서 빠지고, 누구에게도 켜지지 않습니다. 숨긴 기능은 다음 업데이트에서 앱에서 지웁니다(그 전까지는 복귀 건의로 되돌릴 수 있음)
  - 정식으로 올라간 기능은 다음 업데이트에서 실험실 목록을 떠나 늘 있는 기능이 됩니다
  - 복귀: 바로 숨긴 기능은 숨기기 전 상태로, 정식이 된 기능은 다시 실험실로 돌아갑니다
- **GitHub 로그인 없이 요청받기**: 중계 서버를 설정하면(`relay/README.md`) 평가단이 앱에서 평가단 코드만 입력하고 바로 요청합니다. 설정하지 않으면 아래의 이슈 방식으로 동작합니다
- 이슈 방식에서 요청할 수 있는 사람은 저장소 주인과 `release/panel.txt`에 적힌 GitHub 계정입니다. `*` 한 줄을 적으면 누구의 요청이든 받습니다
- 처리는 `.github/workflows/panel.yml`과 `scripts/panel.py`가 합니다. 자동으로 커밋이 올라가므로, 직접 작업할 때는 먼저 `git pull`을 하세요
- 실험실 기능을 새로 만들 때는 `Labs.kt`의 목록과 `release/labs.json`의 `features`에 같은 이름을 넣습니다

## PC와 연결

`설정`에서 둘 중 하나를 고릅니다.

### 블루투스 키보드 (기본)

PC에 아무것도 설치하지 않습니다. 태블릿이 블루투스 키보드로 인식됩니다.

1. 앱의 `설정`에서 `PC에서 검색 허용`을 누릅니다.
2. PC의 블루투스 설정에서 장치 추가로 태블릿을 찾아 연결합니다.
3. 다음부터는 앱을 켜면 마지막 PC에 자동으로 연결됩니다.

이미 태블릿과 PC가 페어링되어 있었거나 이전 버전에서 페어링했다면(1.2에서 마우스 기능이 바뀜) 양쪽에서 페어링을 지우고, 앱의 설정 화면을 켠 상태로 다시 페어링하세요.
일부 기기는 제조사가 이 기능(HID 기기 프로필)을 꺼 두어 쓸 수 없습니다. 그때는 아래 방식을 쓰세요.

### Wi-Fi / USB 테더링

지연이 가장 적습니다. PC(Windows)에서 수신 프로그램을 실행해 둡니다.

1. PC 브라우저에서 아래 주소로 `ControlPadReceiver.exe`를 받습니다. 설치는 필요 없습니다.
   https://raw.githubusercontent.com/jkyou1127-ship-it/control/claude/vibrant-ramanujan-pdzsly/release/ControlPadReceiver.exe
2. 실행한 뒤 앱의 `설정 > Wi-Fi / USB 테더링`에서 `PC 자동으로 찾기`를 누릅니다. PC가 하나면 바로 연결되고, 여러 대면 고르는 창이 뜹니다.
   - 찾지 못하면 수신 프로그램 창의 `이 PC 주소`를 직접 입력하고 `저장하고 연결 확인`을 누릅니다(`복사` 버튼으로 복사할 수 있습니다).
3. 쓰는 동안 창을 열어 둡니다. 닫으면 끝납니다.

수신 프로그램 창(브라우저를 열지 않는 자체 창)에서 할 수 있는 것:
- 연결 상태, 누른 횟수, 초당 입력 수와 최고 기록, 지금 누르는 키, 최근 입력 보기
- `입력 일시정지`(받기는 하되 PC에 넣지 않음), `모든 키 떼기`(키가 눌린 채 남았을 때)
- `항상 위에 표시`, `Windows 시작 시 자동 실행`(로그인하면 관리자 권한으로 권한 요청 없이 켜짐)
- 최근 1분 입력 그래프, 연결이 끊기면 `연결 끊김` 표시
- 어디서든 `Ctrl+Alt+P`로 입력 일시정지 / 다시 받기. 일시정지 중이면 태블릿 앱의 연결 상태에도 표시됩니다
- 창 위치를 기억해 다음에 같은 자리에 엽니다
- 창 테마 12개(다크, 블랙, 라이트, 미드나잇, 포레스트, 와인, 오션, 사이버펑크, 라벤더, 터미널, 신스웨이브, 앰버): 창 아래쪽 `테마`의 ◀ ▶로 바꿉니다
- 전체 화면: `F11` 또는 `⛶ 전체 화면` 버튼(돌아오기는 `Esc`). 내용을 화면 높이에 맞게 키워 가운데에 둡니다. `-fullscreen`을 붙여 실행하면 전체 화면으로 시작합니다
- `통계 초기화`(누적 횟수는 남김), 누적 입력 수, `연결 알림음`, `마우스 감도`(0.25~3배, 트랙패드 · 가상 마우스 이동)
- 화면이 작으면 창 내용을 자동으로 줄여 모두 보이게 합니다
- `▣ 미니 모드`: 연결 상태와 지금 누르는 키만 크게 보여 주는 작은 창(방송 화면에 띄우기 좋음)
- `창 투명도`(100~60%), `이 태블릿만 받기`(지금 연결된 태블릿 말고는 찾기 요청까지 무시), `업데이트 확인`(새 버전이 있으면 바로 업데이트)

- 서명되지 않은 프로그램이라 처음 실행할 때 Windows가 "PC 보호" 경고를 띄웁니다. `추가 정보 > 실행`을 누르면 됩니다.
- Windows 방화벽이 물으면 허용하세요.
- 관리자 권한으로 실행된 게임에도 입력이 들어가도록, 켤 때 관리자 권한을 요청합니다(`예`를 누르세요).
- 실행할 때마다 새 버전을 확인해 스스로 업데이트합니다(`-no-update`를 붙여 실행하면 확인하지 않음).

소스는 `receiver/go/`에 있고 `scripts/build-receiver.sh`로 빌드합니다. Python이 있다면 같은 일을 하는 `receiver/controlpad_receiver.py`를 써도 됩니다.

## 업데이트

**채널 이름**: 가장 새 빌드는 `알파`(release/alpha/), 한 단계 전 빌드는 `최신`(release/, 예전 이름 정식)입니다.

**버전 이름**: 코드명(`hd12`, `versionName`)은 버전을 확인할 때(업데이트 비교, 평가단 빌드 요청) 쓰고, 빌드 번호(`NWE 01`, `Updater.BUILD`)는 화면에 보여 줄 때 씁니다. `publish.sh`가 둘 다 `version.json`에 적습니다. 그 전에는 `NES2`, `NCP#1.00.a`였습니다. 따로 정하지 않으면 코드명과 빌드 번호는 같게 하고, 실험실 기능만 더한 업데이트는 이름 끝에 `+`를 붙입니다.

**평가단 OK가 필요한 빌드**: 큰 개편(예: UI 대개편)은 `scripts/publish.sh --needs-panel`로 알파에 올립니다. 이런 빌드는 평가단이 `빌드 정식 추가`를 건의해야 정식에 올라가고, 그 전에는 다음 빌드를 내도 정식으로 자동으로 내려가지 않습니다.

`설정 > 업데이트 내역`에서 버전별로 바뀐 점을 봅니다. 업데이트한 뒤 처음 켜면 이번 버전에서 바뀐 점이 한 번 표시됩니다.
버전 번호: 예전에 1.x 로 부르던 버전은 BETA, 2.x 로 부르던 버전은 1.x 입니다(예: 예전 2.18 = 지금 1.18).
새 버전을 낼 때는 `Changelog.kt` 맨 위에 항목을 하나 더합니다.

앱을 켜면 새 버전을 확인하고, 있으면 묻지 않고 바로 내려받아 설치합니다(`설정 > 자동 업데이트`, 기본 켜짐). 끄면 설치할지 먼저 묻습니다.
안드로이드 12 이상에서는 앱 안에서 한 번 업데이트한 뒤부터 설치 확인 창도 뜨지 않습니다. 설치가 끝나면 앱이 닫히니 다시 켜면 됩니다. `설정 > 업데이트 확인`으로 직접 확인할 수도 있습니다.
처음 업데이트할 때 안드로이드가 "이 출처의 앱 설치 허용"을 한 번 묻습니다.

채널이 둘입니다.

| 채널 | 폴더 | 내용 |
|---|---|---|
| 알파 | `release/alpha/` | 가장 최신 빌드. 올리는 즉시 받습니다 |
| 정식 (기본) | `release/` | 한 번 전의 빌드. 새 빌드는 그다음 빌드가 나올 때 정식으로 넘어옵니다 |

알파를 받으려면 `설정 > 알파 빌드 받기`를 켭니다.

새 버전을 배포하려면 `app/build.gradle.kts`의 `versionCode`/`versionName`을 올리고 아래를 실행한 뒤 커밋·푸시합니다.
지금 알파에 있던 빌드가 정식으로 내려가고, 새 빌드가 알파에 올라갑니다.

```bash
scripts/publish.sh "이번 버전에서 바뀐 점"
```

버그 수정은 기다리지 않고 두 채널에 같이 올립니다.

```bash
scripts/publish.sh --fix "고친 점"
```

앱은 `Updater.kt`의 `BASE` 주소(현재 `claude/vibrant-ramanujan-pdzsly` 브랜치)에서 받아 옵니다.
